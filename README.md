# md2publish

把 Markdown（或 PPTX 演示文稿）直接转换成更适合发布的内容，并分别生成：

- 知识星球版
- 微信公众号版
- 小红书图文（3:4 卡片图片 + 文案）

## 功能

- 粘贴 Markdown，或直接导入一个 `.md` / `.markdown` 文件，也可导入一个 `.pptx` 演示文稿（自动转换为 Markdown）
- 导入文件时可同时选择文中引用的本地图片，工具会将其内联到预览和剪贴板
- 自动处理标题、段落、列表、引用、代码块、图片和表格
- Markdown 图片会输出为真实图片，并以等比例自适应宽度显示
- 微信公众号“复制”会自动把表格渲染为 2 倍分辨率 PNG，并按原文位置嵌入，避免编辑器压缩或改乱表格样式
- 知识星球“复制文章”会自动把全部表格渲染为 2 倍分辨率 PNG，并按原文位置嵌入富文本，绕过编辑器对 `table` 标签的过滤
- 微信公众号剪贴板同时包含 HTML 和纯文本备用格式
- 支持将知识星球版或微信公众号版切换到整屏预览模式，并在整屏模式内手动调节阅读宽度
- 右侧预览区通过「知识星球 / 公众号 / 小红书」标签页切换，切换时保留各平台的复制状态和已生成的卡片
- 小红书版连续排版并按实际高度自动拆分 1080×1440 卡片，可单张复制/下载，或连同文案打包下载 zip；代码块渲染为带语法高亮、行号和行级标注的代码窗口，引用渲染为分类配色的提示卡片
- 知识星球版支持两种复制模式：
  - **复制文章**：复制整篇富文本，自动将所有表格转为高清图片
  - **复制表格图片**：只复制当前表格图片，适合单独补贴或重试

## 环境要求

- Node.js `20.19+` 或 `22.12+`，推荐安装 Node.js 22 LTS
- npm（安装 Node.js 时会一并安装）
- 最新版 Chrome 或 Edge
- 不要直接双击打开 `index.html`；请通过下面的 Vite 本地服务访问，保证剪贴板 API 正常工作

可以先检查环境：

```bash
node -v
npm -v
```

## Windows 使用方法

### 一键启动（推荐）

双击项目目录里的 `start-dev.bat`（或桌面上的「md2publish」快捷方式）即可：

- 首次运行会自动执行 `npm install` 安装依赖
- 之后会启动开发服务器，并在就绪后**自动打开浏览器**访问 `http://127.0.0.1:43187/`
- 如果服务器已经在运行，再次双击只会打开浏览器，不会重复启动
- 关闭弹出的「md2publish dev server」命令行窗口（或在其中按 `Ctrl+C`）即可停止服务

前提：已安装 Node.js 22 LTS（`node -v` 可正常输出）。

### 手动启动

1. 从 [Node.js 官网](https://nodejs.org/)安装 Node.js 22 LTS。
2. 打开 PowerShell，进入项目目录：

```powershell
cd C:\path\to\md2publish
```

3. 首次运行时安装依赖：

```powershell
npm install
```

4. 启动项目：

```powershell
npm run dev
```

5. 使用最新版 Chrome 或 Edge 打开终端显示的地址，通常是：

```text
http://127.0.0.1:43187/
```

> ⚠️ 在 Windows 上请始终使用 `127.0.0.1` 而不是 `localhost`：`localhost` 会优先解析为 IPv6 回环地址 `::1`，而部分 Windows 机器的防火墙会拦截 IPv6 回环连接，导致 Vite 终端显示 `ready` 但浏览器报 `ERR_CONNECTION_REFUSED`。项目已在 `vite.config.ts` 中通过 `server.host: '127.0.0.1'` 将开发服务器固定绑定到 IPv4 回环地址。

6. 粘贴或导入 Markdown，点击知识星球版的「复制文章」，等待页面提示表格已经转为高清图片，然后粘贴到知识星球编辑器。微信公众号使用右侧的「复制」按钮。
7. 使用结束后回到 PowerShell，按 `Ctrl+C` 停止服务。

项目固定使用较少见的 `43187` 端口。如果该端口被其他程序占用，启动器会提示冲突，不会打开其他应用的页面。

## macOS 使用方法

### 一键启动（推荐）

双击项目目录里的 `start-dev.command` 即可：

- 首次运行会自动执行 `npm install` 安装依赖
- 之后会启动开发服务器，并在就绪后**自动打开浏览器**访问 `http://127.0.0.1:43187/`
- 如果服务器已经在运行，再次双击只会打开浏览器，不会重复启动
- 关闭弹出的“终端”窗口（或在其中按 `Control+C`）即可停止服务

前提：已安装 Node.js 22 LTS（`node -v` 可正常输出）。脚本同时兼容 Apple 芯片和 Intel Mac 的 Homebrew 默认安装路径。

如果通过某些压缩或同步工具获取项目后，双击时提示没有执行权限，请在“终端”进入项目目录并执行一次：

```bash
chmod +x start-dev.command
```

### 手动启动

1. 从 [Node.js 官网](https://nodejs.org/)安装 Node.js 22 LTS；如果已经安装 Homebrew，也可以执行：

```bash
brew install node
```

2. 打开“终端”，进入项目目录：

```bash
cd /path/to/md2publish
```

3. 首次运行时安装依赖：

```bash
npm install
```

4. 启动项目：

```bash
npm run dev
```

5. 使用最新版 Chrome 打开终端显示的地址，通常是：

```text
http://127.0.0.1:43187/
```

也可以在终端中执行：

```bash
open http://127.0.0.1:43187/
```

6. 粘贴或导入 Markdown，点击知识星球版的「复制文章」，等待表格图片生成和复制完成，再粘贴到知识星球编辑器。微信公众号使用右侧的「复制」按钮。
7. 使用结束后回到终端，按 `Control+C` 停止服务。

macOS 建议优先使用最新版 Chrome。Safari 可以打开和预览页面，但其剪贴板权限和用户激活规则更严格，表格图片生成后再复制可能失败；遇到复制失败时请改用 Chrome。

## 故障排查

### Windows 上 Vite 显示 ready 但浏览器打不开页面

症状：PowerShell 显示 `VITE ready` 和 `Local: http://localhost:43187/`，但浏览器报 `ERR_CONNECTION_REFUSED` 或 `EACCES`。

原因：`localhost` 优先解析为 IPv6 回环地址 `::1`，而部分 Windows 机器的防火墙会拦截 IPv6 回环连接。项目已固定 dev server 绑定到 `127.0.0.1`（见 `vite.config.ts` 的 `server.host`），但**浏览器地址栏仍可能访问 `localhost`（`::1`）而被拦截**。

解决：

1. 始终使用终端输出的完整地址 `http://127.0.0.1:43187/` 访问，不要手动输入 `localhost`
2. 如果仍打不开，检查是否有残留的旧 dev server 进程占用端口：

```powershell
Get-NetTCPConnection -State Listen -LocalPort 43187
```

找到占用 `43187` 的 `OwningProcess` 后确认它属于哪个程序；关闭该程序后重新 `npm run dev`。

3. 快速判断本机 IPv6 回环是否被拦截：

```powershell
node -e "require('net').connect(0,'::1',()=>process.exit(0)).on('error',e=>{console.log('IPv6 loopback blocked:',e.code);process.exit(1)})"
```

如果输出 `EACCES`，说明是防火墙拦截 IPv6 回环，按第 1 步使用 `127.0.0.1` 即可；如需彻底解决，可在 Windows 防火墙中放行 IPv6 回环连接。

### 端口被占用

一键启动器固定使用 `43187` 端口。如果 md2publish 已经在该端口运行，再次启动只会打开现有页面；如果端口被其他程序占用，启动器会提示错误，请关闭占用程序后重试。

## 使用说明

### 知识星球版复制建议

知识星球会过滤 HTML `table` 标签，因此知识星球输出不再直接复制真实表格：

1. **复制文章**：一次复制全文，所有表格自动转为高清图片并保留原文位置
2. **复制表格图片**：需要单独补贴某个表格时使用；多次点击会依次复制下一张表格

重复表格会保留原始 PNG 像素，并加入不同的图片标识，避免知识星球按相同图片地址去重后漏传。粘贴后请等待所有图片上传完成再发布；平台提示“复制过来的图片内容超长”也可能表示仍有图片未完成上传，并不一定是图片文件过大。

知识星球单篇正文有 **100,000 字符**上限，超出后粘贴可能直接截断尾部。工具会估算实际富文本正文长度（表格转为图片后不计表格文字，也不计图片 Base64），超过 **95,000 字符**时按章节分篇，保留粘贴余量。普通预览和整屏预览均会显示分篇提示与篇章选择器；选择各篇后点击「复制第 N/M 篇」，分别粘贴到**不同的新文章**，不能追加到同一篇。预览始终展示全文；单个内容块仍超过安全上限时，会提示先拆分该段落、列表或代码块，避免复制后丢失内容。

### 导入本地图片

点击「导入 Markdown/PPTX/图片」，一次选择一个 Markdown 文件和它引用的图片。远程 `http` / `https` 图片无需额外选择；本地相对路径图片会按完整相对路径优先匹配，在文件选择器不提供目录信息时再按唯一文件名匹配。若有图片未找到，页面会列出缺少的路径。

### 导入 PPTX

点击「导入 Markdown/PPTX/图片」并选择一个 `.pptx` 文件，工具会在浏览器本地把它转换为 Markdown 并填入左侧编辑器，三个平台共用这份内容，可继续编辑后再发布：

- 第一页若为标题页，其标题作为一级标题、副标题作为导语；否则使用文件名作为一级标题
- 其余每页的标题转为二级标题，页与页之间插入 `---`（小红书版中会另起一张卡片，公众号和知识星球输出不受影响）
- 正文按段落级别转为多级列表，保留加粗；表格转为 Markdown 表格；PNG / JPG / GIF / SVG / WebP 图片会一并载入
- 隐藏页、日期/页脚/页码占位符不导入；EMF / WMF 等浏览器无法显示的图片、图表和 SmartArt 会跳过并在导入提示中说明

只支持文本内容转换，不保留 PPT 的版式与动画；旧版 `.ppt` 请先在 PowerPoint 中另存为 `.pptx`。

### 小红书版

切换到「小红书」标签页，点击「生成卡片」：

1. 卡片为 3:4 竖图（导出 1080×1440 PNG），标题紧随前面的正文，不再自动另起一张；空间不足时按实际排版高度分页，并尽量让标题与后续正文同页。长段落按句、长列表按项、长代码按行（续页标注「（续）」）、长表格按行（续页重复表头）拆分
2. 在 Markdown 中写一行 `---` 可强制从下一张卡片开始；这只影响小红书版
3. 默认生成封面卡：一级标题作为大标题、不超过 60 字的导语作为副标题、二级标题作为要点
4. 可设置系列名（左上角）、署名（卡片左下角，并自动加入正文文案末尾、话题标签之前）、话题标签和 4 套配色主题；设置会保存在浏览器本地。修改署名立即更新卡片、复制文案和 ZIP 内的文案，保留已手动编辑的正文。修改主题、封面开关或「代码显示行号」后会自动重新排版（已编辑的文案保留）；修改原文后需点击「重新生成卡片」
5. 文案区自动生成标题（≤ 20 字）和正文（≤ 1000 字，末尾附话题标签），可直接编辑，「复制文案」一键复制

#### 代码块与引用的卡片样式

代码块渲染为「代码截图」风格的窗口：macOS 三色圆点、语言名标题栏、行号、语法高亮、圆角和阴影。纸感米白 / 经典红使用深色 Mocha 配色，莫兰迪使用浅色 GitHub Light，深色终端使用 Slate。

- 语法高亮支持 SystemVerilog / Verilog（`sv`、`systemverilog`、`v`、`svh`）、VHDL、C / C++、Python、Bash / Shell、Tcl、Perl、Makefile、JavaScript / TypeScript、JSON、YAML、Markdown；其他语言按纯文本显示，窗口样式不变
- 超过 48 列的长行把整块代码字号缩小 1px，超过 60 列缩小 2px（中文按 2 列计算）；折行的续行向右缩进 2 个字符，行号始终与代码首行对齐
- 长代码拆到多张卡片时，行号接续上一张，跨行注释和字符串的颜色保持连续
- 「代码显示行号」开关和可折叠的「代码样式」区（行号文字色、行号背景色、恢复主题默认）位于设置区；行号颜色按主题分别保存，修改后预览立即更新，无需重新排版；文章中没有代码块时行号开关不可用

在代码围栏上可以指定起始行号和高亮行，行号均为**卡片上显示的行号**（绝对行号）：

````markdown
```sv {start=10} {12,15-17}
...
```
````

- `sv:42` 或 `{start=42}`（也可写 `startLine=42`）：从第 42 行开始编号；两者同时出现时以 `start=` 为准
- `{12,15-17}`：高亮第 12、15、16、17 行

还可以在代码行末尾用注释写行内标记（支持 `//`、`#`、`--`、`;` 四种注释前缀），标记后的文字会显示为行尾气泡：

```sv
always_ff @(posedge clk) begin
  if (!rst_n)        // [!code focus]
    cnt <= '0;       // [!code highlight]
    cnt <= cnt + 1;  // [!code ++]
    cnt <= cnt - 1;  // [!code --]
  overflow <= &cnt;  // [!code warning] 注意位宽
end
```

| 标记 | 效果 |
|---|---|
| `[!code highlight]` | 强调该行 |
| `[!code focus]` | 聚焦该行，同一代码块中其他行变淡 |
| `[!code ++]` / `[!code --]` | 新增 / 删除（行号处显示 `+` / `−`，删除行加删除线） |
| `[!code warning]` / `[!code error]` | 告警 / 错误，适合配合行尾说明 |

标记（连同标记后的说明文字）在知识星球、公众号和小红书三个平台都会被去掉，说明文字只以气泡形式出现在小红书卡片上；因此代码中原本就写着 `// [!code …]` 的文字也不会保留。解析 Markdown 时会去掉代码块开头的空行，起始行号从第一行非空代码开始计算。

引用块使用斜向渐变底、左侧色条、右上角大号半透明引号和阴影；`[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]`、`[!CAUTION]` 分别显示为「ℹ 说明」「✓ 提示」「! 重要提示」「⚠ 注意」「✕ 警告」胶囊标签和各自配色，拆到下一张卡片的部分标注「· 续」。以上样式只用于小红书卡片，公众号和知识星球的排版不变。

卡片截图使用 html2canvas-pro，阴影等效果与预览一致。代码和引用样式会改变卡片高度，更新后请点击「重新生成卡片」再导出。

小红书单篇笔记最多 **18 张**图片。超过时页面会提示，「下载全部（zip）」会按每 18 张分到 `part1/`、`part2/` 等目录，每组附一份带「（1/2）」序号的 `caption.txt`，可分多篇发布。

例如生成 19 张时，ZIP 内的 `part1/` 有 18 张、`part2/` 有 1 张，总数仍为 19 张。导出会校验图片数量；若提示导出失败，本次不会下载新的 ZIP，请勿将之前下载的旧文件当成本次结果。刷新当前开发服务页面（默认 `http://127.0.0.1:43187/`）后可重试。

单张无法容纳且无法拆分的内容（如超高图片）会给出提示。远程图片若不允许跨域访问，卡片中会显示占位框，建议把配图与 Markdown 一起导入。

### 微信公众号版

直接使用「复制」按钮。复制内容包含真实图片、自动生成的高清表格图片和纯文本备用格式；标题、正文及提示块使用适合公众号编辑器的内联排版样式。一级、二级、三级标题分别使用蓝色、紫色、青绿色，复制内容内联保留标题颜色；预览与复制时自动去掉正文中的 `[5]`、`[5][3][2]` 这类数字引用标号，代码和转义后的字面标号保留。

公众号编辑器提示正文不能超过 **50,000 字**。工具按每篇 **45,000 字符**的安全容量分篇，预留余量；估算同时覆盖富文本和纯文本备用格式，因此表格文字在纯文本中占用的容量也会计入。普通预览与整屏预览均可选择篇章，依次复制到**不同的新文章**。富文本复制失败时，也只降级复制当前篇的纯文本。两个平台的篇章选择相互独立，修改或重新导入原文后会回到第 1 篇。
